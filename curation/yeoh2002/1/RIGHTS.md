# Yeoh2002 source license

The Bioconductor 3.5 release page and the pinned source archive's
`DESCRIPTION` both declare `LGPL (>= 2)`. The package is an experiment-data
release by Benjamin Georgi, Matthias Heinig, Sebastian Schmeier, and Joern
Toedling. It contains the processed `stjude` object and documents the
normalization, probe summarization, and original study. The archive declares
no separate terms for that object.
[Bioconductor 3.5 package record](https://mirrors.nju.edu.cn/bioconductor/packages/3.5/data/experiment/html/stjudem.html).

The package notice is the basis for carrying `LGPL-2.0-or-later` forward to
the CSV extract. The staged deposit includes the unchanged source package,
the LGPL text, the conversion script, and documentation crediting the package
and the original study. The repository's MIT license covers the independently
written script and documentation.
[SPDX license record](https://spdx.org/licenses/LGPL-2.0-or-later.html).

St. Jude's ALL1 page describes the underlying study data, and its website
copyright statement limits reuse of the site. The recipe uses Bioconductor's
separately published processed data package. The review makes no finding
about redistribution of St. Jude's website files or Iowa's teaching export.
[St. Jude ALL1 supplemental data](https://www.stjude.org/research/labs/mullighan-lab/supplemental-data/all1.html),
[St. Jude website terms](https://www.stjude.org/legal.html).
