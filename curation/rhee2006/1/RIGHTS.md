# Data rights

Public domain, based on Stanford HIVDB's published-data statement.

Source terms: https://hivdb.stanford.edu/_wrapper/pages/FAQ/FAQ.html

The FAQ states that the database operates on the principle that published data belongs in the public domain so others can verify and build on the results. Johan Larsson reviewed this statement on October 15, 2026, and accepted it as covering redistribution of this dataset. This is the recorded redistribution basis, not a new license grant, a CC0 dedication, or an application of the repository MIT code license to the data.

Original data: Stanford HIV Drug Resistance Database, PI_DATA.txt for Rhee et al. (2006), doi:10.1073/pnas.0607274103. Datamonger prepared the CSV following the referenced Iowa Biostatistics recipe. Retain these provenance and citation details when reusing the data.
