# Datamonger for Julia

Retrieve, verify, and decode research datasets with the Julia client.
Start with the [Julia guide](../../pages/julia.md) for installation and dataset access.
See the [complete client guide](https://github.com/jolars/datamonger/blob/main/packages/julia/README.md)
for return types, registry selection, offline use, and cache management.

Use the Julia section in the navigation bar to browse the extracted API reference,
including the generated error types. Function overviews include method documentation,
and equivalent operations link to the Python and R references.

## Tutorials

The [offline data workflow](../../../packages/julia/tutorials/offline-workflow.md)
walks through verified retrieval, typed tables, missing values, sparse data,
train/test splits, and cache management using the shared conformance fixtures.
The [reproducibility guide](../../../packages/julia/tutorials/reproducibility.md)
explains strong selectors, dataset versions, and project configuration.
