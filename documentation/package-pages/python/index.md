# Datamonger for Python

Retrieve, verify, and decode research datasets with the Python client.
The API reference covers dataset operations, registry selection, cache management,
result types, and semantic errors.

Start with the [Python guide](../../pages/python.md) for installation and dataset access.
See the [complete client guide](https://github.com/jolars/datamonger/blob/main/packages/python/README.md)
for return types, registry selection, offline use, and cache management.
